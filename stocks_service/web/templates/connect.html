1. Get an API key

The bearer token is any one of the service's API keys: the comma-separated STOCKS_API_KEYS variable on the Railway stocks service. The examples below read it from an environment variable:

How an agent should use it

{% call ui.card() %}
  1. Identify itself on every call. Every tool requires agent_id, model_id and prompt_version; calls without them are rejected. Each call is logged with what the agent saw and did.
  2. Read the outlook with get_outlook: one row per symbol and side, with the plan (entry limit, stop, target), expected six-month return, percentiles and evidence grade, and placeable_until.
  3. Check the account with get_account (cash, free buying power, positions).
  4. Place orders before the next open with place_paper_order, giving a unique idempotency_key (at least 8 characters; reusing it returns the same order) and a rationale. Orders are DAY limit orders at the row's entry limit, with its stop and target; they are refused after placeable_until, above the account's risk limits, or when the symbol already has an open order or position.
  5. Review results with list_orders and get_performance; pass baseline_account to get the paired comparison with the baseline policy and the influence gate.
{% endcall %}
